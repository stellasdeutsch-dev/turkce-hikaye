# Расскажи о себе по-турецки — Timur Turkish

Гайд уровня B1 по теме «Описывать опыт, события, мечты». Истории из жизни Тимура короткими
рублеными фразами, девять интерактивных блоков, озвучка каждой турецкой фразы. В конце продающий
блок платформы **Alterna Timur A0 → C1** с переходом на оплату в lava.top.

Дизайн повторяет лендинг «Давно пора!» с Behance: светло-серый фон, тонкие заглавные заголовки
с жирной синей второй строкой, красные кнопки-таблетки с подсветкой, синие стеклянные иконки,
3D-коробки на паллете (CSS, без картинок), металлические перила за карточками, водяные знаки
крупным текстом, тарифные карточки. Вёрстка mobile first.

## Анимации

- **Погрузчик** (SVG, рисуется кодом): в первом экране въезжает к паллету, после чего падают коробки; в рекламном блоке привозит коробки «A0 → A2 · B1 → B2 · C1!» и поднимает их вилами. Мигает маячок, идёт дым, крутятся колёса
- **Комната в сцене «фон и событие»**: включается лампа, за окном идёт дождь, из наушников летят ноты, телефон вибрирует, в конце падает печать KABUL!
- **Бегущие ленты** крест-накрест: после вступления и перед рекламой
- **Заголовки** выезжают по словам
- **Конвейер** в конструкторе истории: коробка подпрыгивает при выборе, подсвечивается во время озвучки
- Параллакс водяных знаков, пятен и воздушных шаров, падающие звёзды в «keşke», z-z-Z и искры в банках, эквалайзер в караоке
- 3D-наклон карточек и свечение за курсором (только мышь), рябь на кнопках, пульс вокруг финальной кнопки, телефоны листаются сами
- `prefers-reduced-motion` отключает движение

## Блоки урока

1. **События: -dı** — маркеры времени, карусель из девяти событий жизни, правило Fıstıkçı Şahap с кликабельными буквами
2. **Фон: -ıyordu** — сцена, где полосы фона и вспышки событий появляются синхронно с озвучкой; «режиссёр» переключает точку и полосу; таблица сборки
3. **Опыт: Hiç … mi?** — свайп-карточки влево/вправо, ответ собирается и озвучивается; шкала частоты
4. **Мечты: rüya ≠ hayal** — мини-игра с двумя банками, шесть конструкций мечты
5. **Keşke** — машина желаний: реальность превращается в желание с искрами
6. **Формула истории** — пять правил рассказчика и конструктор на 243 истории, которые можно послушать целиком
7. **Монолог** — караоке с подсветкой текущего предложения
8. **Квиз** — 7 вопросов, конфетти за 6+
9. **Шпаргалка**

## Продающий блок

История-переход → о платформе → кому подойдёт → что внутри (счётчики) → видео по вкладкам →
телефоны → скриншоты с увеличением → честное сравнение трёх путей → калькулятор цены за день →
автор → FAQ → Telegram → финальный CTA с QR. Плавающая кнопка покупки появляется после первого экрана
и прячется у финального блока.

## Озвучка

Тексты для озвучки лежат прямо в `index.html`, в блоках `/*TR*/{…}/*END-TR*/` и `/*RU*/{…}/*END-RU*/`.
Скрипт читает их оттуда, поэтому после правки фразы достаточно перезапустить его:

```bash
bash tools/gen-audio.sh           # только недостающие файлы
bash tools/gen-audio.sh --force   # перезаписать всё
```

Голоса синтезированные (системные голоса macOS), это не запись живого человека. Хочешь свой голос —
запиши mp3 с тем же именем и положи в ту же папку. Если файла нет, сайт включает синтез речи браузера.

## Локальный запуск

```bash
python3 -m http.server 8822
```

Открыть `http://localhost:8822`. Через `file://` озвучка не заработает.
